## パチスロ店 設定良さそう度チェッカー(大阪・奈良エリア)

大阪・奈良エリアのパチスロ店を回る際に、どの店・どの台が良さそうかを判断する材料をまとめて表示する個人用ツールです。`index.html` をブラウザで開くだけで動作します(ビルド不要、サーバー不要)。

### 使い方

1. `index.html` をブラウザで開く(またはGitHub Pagesなどで公開する)。
2. 店舗一覧には大阪・奈良エリアの実在店舗を参考情報としてあらかじめ何件か登録しています。「店舗を追加」「編集」「削除」で自由に調整してください。
3. 各店舗カードの「実戦データを追加」から、LINE通知(データスコープ等)やアナスロなどで確認した差枚・G数・BB/RB回数を入力します。通知本文をそのまま貼り付けると、差枚・G数・BB/RB・台番号を自動で抽出しようと試みます(精度は完全ではないため、保存前に必ず内容を確認してください)。
4. 「口コミを追加」から、5ch・みんパチ・Googleマップなどで見かけた評判の要点を入力します。
5. 各店舗の「実戦データ」「口コミ」バッジと、総合の「おすすめ度」バッジが自動計算されます。データが無い/古い店舗は「情報不足」として扱われ、おすすめとしては表示されません。
6. 入力したデータはブラウザの localStorage に保存されます。他の端末と共有したい場合は「エクスポート」でJSONを書き出し、「インポート」で取り込んでください。

### データ取得方針について

大阪・奈良のパチスロ店の実戦データを提供する「データスコープ」(サイトセブン/ダイコク電機)は、LINE公式アカウント経由で情報を通知するサービスであり、外部から利用できる公式API・オープンデータは公開されていません。また、パチンコ店の口コミ・評判サイト(5ch、みんパチ等)についても、自動スクレイピングは利用規約上の問題があるため行っていません。

そのため本ツールは、ユーザーが実際に受け取ったLINE通知や、閲覧した口コミの内容を**手動でコピペ・入力**し、それを集計・可視化する設計にしています。自動収集は行わず、入力された情報の範囲でのみ判断材料を提示します。

### スコアの考え方

- 実戦データは、入力された差枚・G数・BB/RB回数から算出した簡易的な目安であり、設定判別を保証するものではありません。
- 画面上部の「実戦データの鮮度しきい値」より古いデータしかない場合は「データなし/古いデータ」として扱われ、おすすめには含まれません。
- 口コミは主観的な投稿内容の要約であり、事実の裏付けがあるものではありません。あくまで参考情報としてご利用ください。
- 最終的な判断は、必ず現地の設置状況・出玉状況をご自身の目で確認のうえ行ってください。

### 初期登録店舗について

初期表示される店舗名・エリアは公開情報をもとにした参考情報です。住所・設置台数・営業状況などは変更されている可能性があるため、来店前に必ず最新情報をご確認ください。
